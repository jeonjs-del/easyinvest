# 나의 투자 대시보드

차트 · 관심목록 · 동적자산배분을 한 화면에서 보는 개인용 Streamlit 웹앱. 국내/미국 종목 데이터를 서버(Python)에서 수집하므로 브라우저 CORS 제약이 없습니다.

## 파일
- `app.py` — 대시보드 본체 (UI + 백테스트 엔진)
- `strategies.py` — 동적자산배분 15개 전략 규칙
- `watchlist.json` — 관심목록 (앱에서 자동 생성/수정)

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 네 기능
- **차트**: 종목코드/티커 검색, 1W~All 기간, SMA(5·10·20·50·60·120·200)·EMA(9·21·65) 오버레이, 로그/선형, 날짜·OHLCV CSV 다운로드. 두 지점 클릭으로 구간 등락률 측정 (더블클릭으로 초기화).
- **관심목록**: 등록 종목을 선택 기간(1일~1년) 수익률로 순위화. "디폴트"는 전세계 주요 지수 순위.
- **동적자산배분**: 15개 TAA 전략의 현재 포지션·CAGR·MDD·Sharpe 목록 + 전략 상세(누적수익률 vs SPY, 연월별 히트맵).
- **프리미엄**: 김치프리미엄(업비트 BTC vs 코인베이스 BTC × USD/KRW) · 금치프리미엄(ACE KRX금현물 ETF vs GLD × USD/KRW) 실시간 카드 + 최대 3년 시계열 차트.

## 동적자산배분 15개 전략
BAA 공격형/중도형, 변형·오리지널·가속·종합 듀얼모멘텀, VAA, HAA, DAA, PAA, LAA, RAA, NLX HAA, GTAA, Novell 채권. 규칙은 `strategies.py` 상단 주석과 각 함수 참고. 규칙을 바꾸려면 해당 `strat_*` 함수만 수정하면 됩니다.

## 데이터 관련 주의
- **백테스트 기간**: 무료 ETF 데이터라 상장 이후 구간만 계산됩니다. IEFA·IEMG(2012~), PDBC(2014~) 등을 쓰는 전략은 대략 2013~2015년부터 시작됩니다. 원 사이트(Allocate Smartly)의 1970년~ 백테스트는 유료 확장 데이터라 재현 불가.
- **현재 포지션**은 최신 월말 데이터로 정확히 계산됩니다 (실사용 값).
- FDR 종가가 배당을 완전히 반영하지 않을 수 있어 CAGR·MDD가 원 사이트와 다소 다를 수 있습니다.
- LAA/RAA는 FRED 실업률(UNRATE)을 사용합니다. 미조회 시 시장신호(SPY 200일선)만으로 대체하고 안내가 표시됩니다.
